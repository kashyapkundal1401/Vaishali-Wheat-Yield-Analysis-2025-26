# Vaishali Farmland Analytics: Yield & Profitability Optimization 🌾📊

## Project Overview
This project is a data-driven operational audit of a 6.25-acre wheat enterprise located in Vaishali, Bihar (Rabi Season 2025-26). By transitioning raw agricultural data into structured financial and operational metrics, this analysis identifies critical yield gaps and provides a prescriptive model to maximize net margins. 

The core objective of this project is to demonstrate how data analytics can optimize supply chain access (market vs. MSP) and operational efficiency (conventional vs. zero tillage) in real-world scenarios.

## 🎯 Key Business Problems Addressed
1. **Cost Driver Identification:** Where is the capital being deployed most inefficiently?
2. **Yield Gap Analysis:** What is the financial impact of falling short of target production?
3. **Scenario Planning (What-If Analysis):** How do changes in operational methods and market access affect the final ROI?

## 🛠️ Tech Stack
* **Language:** Python
* **Data Manipulation:** `pandas`, `numpy`
* **Data Visualization:** `matplotlib`, `seaborn`
* **Environment:** Jupyter Notebook / Google Colab

## 📈 Key Insights & Findings
* **The Yield Gap:** The farm achieved **16.8 quintals/acre**, representing a 41% decrease from the target baseline of 28.8 quintals/acre.
* **Market Realization Penalty:** Selling at open market rates (₹1,900/qtl) rather than the government Minimum Support Price (₹2,425/qtl) via PACS registration resulted in a direct revenue loss of **₹55,125**.
* **Operational Overhead:** Utilizing conventional tillage methods incurred a diesel expenditure of ₹28,500. Transitioning to 'Zero Tillage' methods presents an opportunity to reduce fuel costs by ~50% (**₹14,200 savings**).
* **Optimization Potential:** The predictive "What-If" model demonstrates that aligning yield targets, securing MSP pricing, and optimizing fuel efficiency can increase net profit potential by **272%** (from ₹92,075 to ₹343,275).

## 📂 Project Structure
The analysis is structured sequentially within the Jupyter Notebook (`Vaishali_Farmland_Analytics.ipynb`):
1. **Data Initialization:** Structuring raw operational costs (Seeds, Fertilizer, Labor, Diesel) and yield metrics into Pandas DataFrames.
2. **Exploratory Data Analysis (EDA):** Visualizing cost distributions and investment vs. return gaps.
3. **Prescriptive Modeling:** A custom Python function (`predict_my_profit`) that simulates ROI across varying agricultural methods and market pricing scenarios.
4. **Operational Timeline:** A time-series log mapping critical irrigation stages (CRI, Tillering, Milk Stage) to identify potential climatic impacts on yield.

## 🚀 How to Run the Project
1. Clone this repository to your local machine.
2. Ensure you have Python installed along with the required libraries (`pandas`, `matplotlib`, `seaborn`).
3. Open the `.ipynb` file using Jupyter Notebook, Jupyter Lab, or upload it directly to [Google Colab](https://colab.research.google.com/).
4. Run the cells sequentially to generate the financial summaries, visualizations, and predictive scenarios.
